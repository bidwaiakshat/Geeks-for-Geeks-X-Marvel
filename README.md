# AVENGERS: THE INFINITY PROTOCOL

Link: https://avengers-infinity-bennett.lovable.app

AVENGERS: THE INFINITY PROTOCOL is a cinematic event website for the GeeksForGeeks Student Chapter at Bennett University. The concept connects the Avengers’ teamwork with coding, creativity, and collaboration.
The design combines dark backgrounds, Marvel-red accents, character imagery, and an interactive animated arc reactor. Visitors can select a hero, explore the proposed event timeline, and create a downloadable preview pass. Responsive layouts, scroll animations, and accessible motion controls support an immersive experience across desktop and mobile.



4. Relevant resources/assets used
* Development platform: Lovable, with AI-assisted development.
* Technologies: React, TypeScript, TanStack Start, Tailwind CSS, and shadcn/ui.
* Icons: Lucide React.
* Images: Supplied images of Iron Man, Captain America, Thor, and Black Widow from Google. Character artwork belongs to its respective rights holders.
* Branding: MARVEL typographic badge and GeeksForGeeks Student Chapter identification.
* Effects: Custom CSS/SVG arc reactor, scroll reveals, pointer effects, and hero-selection transitions.
* Interactive feature: Downloadable SVG preview pass; not an official registration ticket.
