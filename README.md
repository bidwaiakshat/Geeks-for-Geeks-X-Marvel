# AVENGERS: THE INFINITY PROTOCOL

A cinematic **unofficial student fan event concept** organized by GeeksForGeeks Student Chapter, Bennett University. This front-end concept is not an official Marvel announcement, event registration system, or confirmation of entry. It is not affiliated with Marvel.

## Run locally

Requires Bun or a modern Node.js installation.

```bash
bun install
bun run dev
```

Open the local address printed by Vite. Create a production bundle with `bun run build`; run code style checks with `bun run lint`.

## Experience

- One anchored journey through Mission, Heroes, Timeline, FAQ, and Join the Initiative.
- Four selectable Avengers—Iron Man, Captain America, Thor, and Black Widow—with selection-aware details and preview-pass styling.
- An accessible interactive arc reactor with charged state, scroll reveals, fine-pointer parallax and card tilt, mobile navigation, and a global motion control that respects reduced-motion preferences.
- A client-only **preview pass** creator. Name is required and team name is optional. It downloads a watermarked SVG locally; no personal information is sent or saved. It is not official registration.

## Assets and libraries

- `iron-man.png`, `captain-america.png`, `thor.png`, and `black-widow.png` were supplied directly by the project owner and are stored as durable Lovable Assets. Their licensing or official provenance has not been independently verified. Existing visible marks and credits in the supplied files are preserved.
- Abstract reactor lighting, particles, framing, and wide-canvas atmosphere are original CSS visuals. No replacement character imagery was generated.
- Original vector favicon in `public/favicon.svg`.
- Barlow Condensed and DM Sans from Google Fonts.
- React 19, TanStack Start/Router, Tailwind CSS 4, and lucide-react. The site has no event-data service.
- MARVEL is shown as a simple typographic fan-event badge. Marvel, Avengers, and character names are trademarks of their respective owners; no official affiliation is implied.
